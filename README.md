# ✨ Simple Landing Page

Uma landing page moderna e responsiva construída com **React**, **Tailwind CSS** e **Framer Motion**.  
Este projeto foi criado com foco em estudo e prática de UI, componentização, animações e layout responsivo.

# 🔗 Acesse o projeto em produção:
-  https://gioomoraes.github.io/landing-page/


## 🛠 Tecnologias Utilizadas

- React (Vite)
- Tailwind CSS
- Framer Motion
- Lucide Icons

## ✨ Funcionalidades

- Layout responsivo (desktop e mobile)
- Seção hero animada com Framer Motion
- Menu mobile com animação lateral (slide-in)
- Cards de recursos, depoimentos e seção de preços
- Rodapé com marca e link para política de privacidade
- UI moderna com gradientes e sombras suaves

## ⚙️ Instalação e uso

1. **Clone o repositório**

```bash
git clone https://github.com/Gioomoraes/landing-page
```

2. Acesse o diretório do projeto:

   ```bash
   cd landing-page
   ```

3. Instale as dependências:

   ```bash
   npm install
   ```

4. Inicie

   ```bash
   npm start
   ```
